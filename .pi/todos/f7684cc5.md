Already implemented. The TS contour engine always uses grow animation — hills appear one at a time and swell from 10% to full radius (SWELL_TICKS=15, ADD_HILL_EVERY=1, COVERAGE_TARGET=0.6). Every reroll/mode change/terrain change resets the grow state and starts fresh. The Python had grow as an explicit toggle; the TS version made it the default and only mode.
