Big migration — `src/windows/music-player-window.ts` is 1224 lines with:
- Embedded FFT (Cooley-Tukey radix-2)
- AudioAnalyser class (ffmpeg PCM pipe + spectrum analysis)
- AudioController class (ffplay playback, playlist mgmt)
- 4 VizMode implementations (bars, rings, grid, rain)
- Full WinAMP-style UI with player pane + playlist pane

Strategy: Export AudioController + viz modes from SDK, write thin MicroappHost wrapper.
The PublicAPI (play/pause/stop/next/prev/scrub/volume) maps naturally to microapp commands.
