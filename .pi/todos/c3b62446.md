After a timeline-capture run, review each bar:

For each captured timestamp:
1. What the timeline SAID should be on screen (scene/patch description)
2. What the text screenshot ACTUALLY shows
3. What the PNG screenshot shows
4. Diff: are windows in expected positions? Right sizes? Right content?

This is the feedback loop that tells us if the runner is working correctly.
Do this manually for the first 15-20s test timeline, then consider automating.

Key things to check:
- Are figlet windows sized correctly (not full-width for short text)?
- Are primers at the layout token positions?
- Did theme changes apply?
- Are overlapping windows in the right z-order?
- Did closes actually close?
