Restore handlers should return the actual restored WindowRecord or window id instead of relying on getLastWindow() for geometry/state application.\n\nCurrent problem: async restore handlers may resolve after another window is created, causing getLastWindow() to return the wrong window. Geometry and state then apply to the wrong target.\n\nFiles: src/core/snapshot-registry.ts, src/core/app-controller.ts (restore path)\nAcceptance: restore geometry/state applies to the intended restored window. No getLastWindow() in the restore path.
