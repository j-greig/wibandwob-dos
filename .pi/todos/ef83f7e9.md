## Bug
`companion.smol` opens at default createFrame size (72x20 area) at cascade offset, not at SMOL_W=34 × SMOL_H=12 anchored bottom-right.

## Root cause
`createFrame` sets default size. `positionFrame` sets `frame.frame.width/height/left/top` but `windowManager.registerWindow` may cascade or the blessed layout invalidates the values.

## Fix (already attempted, needs verification)
After `windowManager.registerWindow(frame)`, explicitly call:
```ts
windowManager.resizeWindow(frame.id, SMOL_W, h);
windowManager.moveWindow(frame.id, sw - SMOL_W - 2, sh - h - 3);
```
These use the canonical resize/move path which calls syncShadow correctly.

3. Also test expand: click [↗] — should grow to 34×24 same anchor
