Create `microapps/theattyr/scripts/extract-segment.ts` — a Bun script to find and extract segments from .vt animation files.

**Use case:** Extract the bouncing-text-in-box section from van_halen.vt (and similar) as a standalone primer or .vt clip.

**Approach ideas:**
- Parse VT100 with @xterm/headless, render each frame, detect visual patterns (box-drawing chars, text movement)
- Reference the original Rust theattyr: https://github.com/orhun/theattyr for how it chunks/frames
- Output: either a trimmed .vt file (byte range) or a series of plain-text frames suitable for a primer window
- Could also do byte-range mode: given start/end byte offsets, extract a sub-animation

**Van Halen bouncing box:** Around byte offset 52934 in van_halen.vt — DEC line-drawing box (lqqqk / x / mqqqj) with text bouncing L-R inside it.
