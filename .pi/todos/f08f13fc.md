Two related issues in the figlet font picker:

1. **Preview pane is empty** — should render the current text (e.g. "GHOST") in the selected font as you browse. The data is right there (`currentText` + selected font), just needs `renderFiglet(currentText, selectedFont)` in the preview update.

2. **`captureText` / `wibwob screenshot` of the font picker should export the rendered preview** — currently only shows font names and metadata. The preview pane content should be included in text export so agents can see what the font looks like.
