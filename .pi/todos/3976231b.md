Ref: https://github.com/j-greig/wibandwob-dos/issues/108

Commands that need to replace bespoke HTTP endpoints must accept args first.

- [ ] editor.open: accept filePath, title, initial args
- [ ] document.open: accept filePath arg
- [ ] chrome.open: accept url arg
- [ ] workspace.save: accept name arg
- [ ] workspace.load_named: accept name arg
- [ ] window.export_text: accept id, label args

Pattern: args = direct action, no args = interactive fallback (like figlet.open, primer.open).

Test: /commands/run with args produces same result as equivalent bespoke HTTP endpoint.

Files: command-catalog.ts, app-controller.ts
