Poetry Clock sentient/liminal/terrain modes require LLM inference. Docker smoke container has no ANTHROPIC_API_KEY — modes other than plain clock will silently fail or error.

Options:
A) Graceful fallback — if no API key, force clock mode and show a status message instead of crashing
B) Pass ANTHROPIC_API_KEY into container at runtime via -e flag (leaks key into container)
C) Document that inference modes require key injection

Prefer A: the clock should degrade gracefully to plain time display with a visible note.
