## Candidates for parallel subagent migration
Each gets one subagent with the proven pattern:

- [ ] `monster-cam-window.ts` → `microapps/monster-cam/` (webcam + ffmpeg)
- [ ] `terrain-lab-window.ts` → `microapps/terrain-lab/` (contour engine)
- [ ] `backrooms-log-browser-window.ts` → `microapps/backrooms-log-browser/`
- [ ] `music-player-window.ts` → `microapps/music-player/` (ffplay)

## NOT candidates (need upstream refactoring)
- `browser-windows.ts` — god-file decomposition first
- `text-windows.ts` — EditorCoordinator coupling
- `scramble-window.ts` — core host surface
- `chrome-browser-window.ts` — CDP integration

## Per-agent instructions
1. Read the source file fully
2. Scaffold microapp: `bash scripts/scaffold-microapp.sh microapps/<name> wibwob.<id> "<Title>" <order>`
3. Write manifest + implementation using SDK-only imports
4. Remove catalog entry + actionKey + shim method from app-controller
5. Remove snapshot-registry handler
6. Add short alias in LEGACY_COMMAND_ALIASES
7. Add to microapp-registry.ts
8. bun run typecheck
9. DO NOT restart or test (parent agent handles that)
