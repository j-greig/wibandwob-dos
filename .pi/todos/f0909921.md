When `autoSizeWindow()` calculates `targetW` from `contentSize.width + 4`, the +4 isn't enough to account for window chrome (borders, toolbar buttons `[V] All [S] Favs [F] Font [E] Edit`). Title gets clipped (`-- Banner: GHOST` instead of `+- Banner: GHOST ... x -+`). Toolbar text input gets squished. Need to add chrome width (toolbar buttons ≈ 48 chars) to the minimum width calculation, or measure the toolbar actual width and use `Math.max(contentWidth + 4, toolbarWidth + 4)`.
