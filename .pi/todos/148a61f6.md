When a tool run is in-progress (active=true), show a braille dot spinner animation
before "Working..." instead of the static ⟳ icon.

Characters: ⠋ ⠙ ⠹ ⠸ ⠼ ⠴ ⠦ ⠧ ⠇ ⠏ (cycle at ~80ms)

Needs a createTimer in the agent window that ticks the spinner frame and
re-renders the active collapsible block's summary line. Clear the timer
when the run closes (active=false).

Depends on: collapsible tool blocks working correctly first.
