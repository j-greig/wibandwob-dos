## Goal
Scramble should be reachable via `send_to_session "scramble"` from the Wib&Wob agent and any other pi session. Currently she has no session socket.

## How it works (existing infra)
- `src/services/pi-session-bridge.ts` exports `startSessionServer({ sessionId, send, getLastReply, abort, reset })`
- `WibWobAgentSession.initialize()` calls this at line ~604, registering a socket at `~/.pi/session-control/<sessionId>.sock`
- Named alias: `~/.pi/session-control/wibwob-tui.alias` → so you can `send_to_session "wibwob-tui"`
- `send_to_session` delivers a message by calling the `send` callback

## What to add

In `src/services/scramble-brain.ts`:
1. Import `startSessionServer` from `../services/pi-session-bridge.js` (or wherever relative)
2. Add `private sessionServer?: { close: () => void }` field
3. Add `startSessionSocket()` public method:
```ts
startSessionSocket(): void {
  if (this.sessionServer) return;
  try {
    this.sessionServer = startSessionServer({
      sessionId: this.sessionId,        // "scramble-fed92d" etc
      send: (text, _sender) => void this.send(text),
      getLastReply: () => this.history.at(-1)?.content ?? null,
      abort: () => this.abort(),
      reset: () => { this.history.length = 0; this.abort(); },
    });
  } catch { /* non-fatal */ }
}
```
4. Call `stopSessionSocket()` in `dispose()`:
```ts
stopSessionSocket(): void {
  this.sessionServer?.close();
  this.sessionServer = undefined;
}
```

In `src/core/app-controller.ts`:
- After `scrambleBrain` field initialisation, call `this.scrambleBrain.startSessionSocket()` in the constructor
- This makes Scramble discoverable via `list_sessions` as `"scramble-XXXXXX"`

## Named alias
Consider registering `"scramble"` as the alias name (not just the session ID) so agents can reliably use `send_to_session "scramble"`. Check `startSessionServer` signature for an alias param.

## Verification
From a pi session: `list_sessions` should show Scramble. `send_to_session "scramble" "hello"` should trigger `brain.send("hello")` and her reply should appear in the floating window.
