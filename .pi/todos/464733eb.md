Add screenshot capture to timeline-run.ts (or a new timeline-capture.ts script).

After each cue fires, capture:
1. Text screenshot via GET /screenshot/text (full TUI as text)
2. PNG screenshot via scripts/screenshot-window.sh or similar
3. Save both to a timestamped capture directory

Output structure:
  scratch/timeline-captures/YYYY-MM-DDTHH-MM-SS/
    timeline.json          — copy of the timeline file used
    bar-01_t00.0s.txt      — text screenshot
    bar-01_t00.0s.png      — PNG screenshot (if possible)
    bar-02_t02.0s.txt
    bar-02_t02.0s.png
    ...
    capture-log.jsonl       — machine-readable log of each cue + capture path

The capture-log.jsonl should record:
- cue index, timestamp, cue type (scene/patch/command)
- expected visual state (from timeline)
- capture file paths
- desktop state snapshot at capture time
