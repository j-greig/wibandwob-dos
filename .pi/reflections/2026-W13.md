# W13 — Week of 2026-03-23

## Monday — Ghostty shaders + View menu + /plan prompt

### `ghostty-shader.sh` config path discovery — Ghostty 1.3 changed filename
Script assumed `config`, Ghostty 1.3+ uses `config.ghostty`. Cascade fallback works: try newest first, then older, then XDG. Lesson: version-dependent paths need ordered discovery, not hardcoded.

### `fswatch` watcher dies immediately when spawned from `bash script.sh`
`disown` doesn't survive non-interactive shell exit — child gets SIGHUP. Inline `bash -c` with complex quoting (osascript + escaped quotes) also fails silently. Fix: write watcher body to a temp script file, run with `nohup bash $tmpfile &`. Works reliably.

### `pgrep -x Ghostty` misses running process — binary is lowercase `ghostty`
macOS app bundle name ≠ binary name. `pgrep -xi` (case-insensitive) is the correct check.

### Dynamic menu commands added after `buildMenus()` don't appear
`addDynamic()` registers the command, but `buildMenus()` snapshots at call time. If registration happens after build, the item exists in the command list but not in the rendered menus. Fix: register dynamics *before* `rebuildMenusFromCommands()`.

### `ghosttyShaderList` split bug — space-separated parsed as newline
The `list` subcommand outputs `wibwob-crt wibwob-glow ...` on one line. `.split("\n")` returns one giant item. `.split(/\s+/)` fixes it. Pre-existing bug — all 3 shader API commands were also using a nonexistent script path (`scripts/ghostty-shader.sh`).

### Reloading TUI code requires full quit + relaunch, not just Ctrl+C
Ctrl+C in tmux restarts the same process with cached bytecode. Need Ctrl+Q (app quit) then `bun run dev:world`. Ghostty AppleScript can drive this. Built `restart-wibwob.sh` to automate the cycle.

### Plan prompt (`/plan`) — phase-gated thinking works
Forcing orient→draft→review→elevate as distinct phases caught the architecture violation (shader logic in app-controller vs service) and the pre-existing bugs before any code was written. Writing the plan to `scratch/plans/` aids session resumption. Key additions: ground-truth gate (read PHILOSOPHY.md + ARCHITECTURE.md), simplicity escalation trigger (>3 files → run `/simplicity-review`), evidence beat (how do you prove it works).

### `scratch/.ghostty-shaders` → `.ghostty-shaders` refactor
Runtime config files that Ghostty's `config-file = ?path` references shouldn't live in `scratch/` (gitignored wholesale, feels transient). Repo root + explicit `.gitignore` entry is more intentional.

### `index.sh` exists but agents don't use it
ghostty-control skill has an `index.sh` that lists all scripts. Never used it this session — always went straight to SKILL.md or individual scripts. Discovery tools are useful on first encounter, then get skipped. The hot path is remembering the script name, not listing them.
