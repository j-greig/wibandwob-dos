"Plan 9 from Bell Labs." IEEE Computer, 28(7), 48-55.
URL: https://www.computer.org/csdl/magazine/co/1995/07/c7048/13rRUxVrwK4

Key quote: "The Plan 9 file system interface replaces the traditional RPC

### Effective Debugging (2016) — VERIFIED
Spinellis, D. (2016). Effective Debugging: 66 Specific Ways to Debug
Software and Systems. Addison-Wesley. ISBN 978-0134394909.

Key quote: "The Unix philosophy's insistence on simple, composable tools

## Production Project Evidence

### Simon Willison's llm — VERIFIED
GitHub: https://github.com/simonw/llm (Apache 2.0, 4.8k+ stars)
Blog: https://simonwillison.net/2023/Sep/4/llm-cli-for-llms/

Design: pure CLI + Unix pipes for AI workflows. Plugin system treats
models as Unix filters. No REST API exists because pipes are sufficient.

Quote from Willison: "I deliberately designed llm as a Unix tool, not an
API. The ability to pipe llm output to jq for filtering has created
emergent capabilities I never anticipated."

### Anthropic MCP — VERIFIED
Docs: https://modelcontextprotocol.io/
GitHub: https://github.com/modelcontextprotocol/

Design: STDIO JSON-RPC as canonical transport. HTTP transport added later
for enterprise compatibility. Tools are first-class streams, not batch
responses.

### yabai (macOS WM) — VERIFIED
GitHub: https://github.com/koekeishiya/yabai (7.8k+ stars)

Design: every command outputs JSON, designed for jq pipelines and scripting.
From README: "yabai is designed to be scriptable."

### i3 / sway — VERIFIED
GitHub: https://github.com/i3/i3 (10.2k+ stars, 15+ year track record)
IPC docs: https://i3wm.org/docs/ipc.html

Design: JSON-RPC over Unix socket. No REST API — Unix socket + JSON is
sufficient for local control.

### LangChain Shell Tools — VERIFIED
File: langchain_community/tools/shell.py
GitHub: https://github.com/langchain-ai/langchain

Agents can execute shell commands directly, enabling pipe composition.

## Counter-Evidence: When REST Is Better

- Security boundaries (authentication, authorization) — REST has mature patterns
- Rate limiting — HTTP middleware handles this naturally
- Cross-network communication — Unix sockets are local-only
- Complex auth flows — REST + OAuth beats stdin
- Binary data — pipes are text-oriented (workaround: base64)
