# W12 — Week of 2026-03-15

## Sunday — Playing with the desktop

**Instance:** a08, phosphor theme, Zilla watching live
**Session vibe:** Sunday afternoon exploration, going nuts with CLI + unix pipes

### What worked beautifully

- **`wibwob map`** — the ASCII spatial map is the best debug tool in the system. Used it constantly.
- **`wibwob plumb --from <id> --to <id>`** — plumbed 6 plasma windows into one notepad. Plumbed DVD figlet + poetry clock + 2 plasmas all into one notepad. The write fallback chain (`<appType>.write` → `.send` → `.create`) found the right command every time.
- **Batch operations** — `POST /windows/batch` with move+resize in one call. 6 windows tiled in a single request.
- **Parallel window spawning** — `for mood in void acid aurora chrome deep-space circuit; do $W cmd plasma.open -- --mood "$mood" &; done` — 6 plasmas spawned concurrently.
- **Unix pipe composition** — extracted glyph census across all 6 plasma renders using `sed 's/./&\n/g' | sort | uniq -c | sort -rn`. Top glyph: `░` (677 occurrences).
- **DVD screensaver** — animated a figlet window bouncing around the desktop with a bash loop + `POST /windows/move` every 150ms. 25 frames, clean bounce physics. Looks great on phosphor theme.

### What broke / friction

- **`desktop.clear-all` race** — if you open windows immediately after clear-all, the IDs can be missing from state for a beat. Need `sleep 0.5` after clear.
- **Contour resize failed silently** — `POST /windows/batch` returned `false` for contour resize. Then contour closed itself? Unclear why. Min-size constraint? Should log a reason.
- **`wibwob cmd figlet.open-default`** — the `--` separator for args is awkward. The view route (`POST /view/figlet/open-default`) was more reliable. CLI should handle this transparently.
- **`terrain_lab.open` vs `terrain-lab.open`** — underscore vs hyphen. Got 404'd. The CLI could fuzzy-match or suggest the right command.
- **`wibwob windows -q` returned empty** after clear-all + rapid open. Timing issue — state hadn't settled.

### Dream features surfaced

1. **`desktop.compose`** — the vision from agent-master-plan.md. One command, declarative layout spec, multi-window workspace in one shot. The bash loop + batch approach works but it's 10 lines when it should be 1.
2. **DVD screensaver as a command** — `desktop.screensaver` that bounces a window. Silly but proves animation is possible via API.
3. **Plumb --all-to** — plumb every open window into one target. Currently requires a loop.
4. **Command fuzzy matching** — `terrain_lab` should find `terrain-lab`. Levenshtein or simple underscore→hyphen normalization.
5. **Batch op failure reasons** — when `/windows/batch` returns `false` for an op, include why (min-size, window-closed, invalid-id).
6. **Write support matrix** — `wibwob commands --writable` to list which appTypes support `.write`. Terrain lab doesn't. Would've saved the 404.

### Observations

- The CLI (`wibwob`) is genuinely pleasant to use once you know the verbs. `map`, `read`, `plumb`, `cmd` cover 90% of what you need.
- Phosphor theme + plasma windows = gorgeous. The aesthetic is right.
- Plumbing is the killer feature. Reading one window's output and piping it into another is the unix philosophy landing in a windowed desktop. This is the COAT thesis proven.
- The `wibwob read <id> | wc -l` and `wibwob read <id> | grep` patterns work exactly as unix expects. Text in, text out, composable.
