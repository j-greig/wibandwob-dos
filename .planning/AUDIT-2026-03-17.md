## Top 5 Most Interesting Forgotten Ideas

1. **Canvas Documents (E028)** — a portable `.canvas.yaml` format where agents can fork, edit, and reload window compositions as human-readable files. This is halfway between a workspace snapshot and a creative medium. In-progress but under-discussed.

2. **CLI Music Videos (E040)** — bash scripts ARE music videos. `ww` commands + `sleep` for timing, record via asciinema. Elegant concept that makes creative output composable and version-controllable. Blocked on E039 unix-cli.

3. **Synesthetic Paint / Diff / Mirror / Zoom (`.fileme/wibwob-command-ideas`)** — Wib vs Wob brainstorm from March 4. Synesthetic Paint (primer → emotional colour field) and Diff (structural delta between two primers) are genuinely novel window types nobody has built.

4. **Visual Self-Scoring for Autoresearch (E038)** — the insight that `log_experiment` accepts any number lets agents self-score creative/visual work against rubrics. Generalised beyond LLM Orch Studio, this becomes an autonomous creative improvement loop. System exists but isn't documented as a reusable pattern.

5. **WibMux (spk-wibmux)** — Ghostty-native tmux replacement using AppleScript. Eliminates the tmux performance tax, ACS garbling, and GPU shader blocking. Technically feasible since Ghostty 1.3's AppleScript API shipped. Would fundamentally change the ops story.
