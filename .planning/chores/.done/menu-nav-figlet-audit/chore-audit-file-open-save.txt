NOTES ON CONSOLIDATION
----------------------
1. Three different "open file" UIs exist:
   a) OverlayManager.openFileBrowserPrompt() -- modal overlay, used by editor, reader, primer, music
   b) createSidebarPanel() + createSelectableList() -- sidebar file list, used by zine, patchbay
   c) openFileManagerWindow() -- full dedicated Far-JS file manager window

2. The Zine has a sidebar that could be replaced by the File menu's open command
   if we want full-screen editing. The "[  ] Files" toolbar toggle and "[" key
   control the sidebar.

3. Save is only in: built-in editor (EditorCoordinator), Slap Editor (EditorEngine),
   and WibWobWorld (auto-save terrain).

4. The built-in editor and Slap Editor are two completely separate editor engines
   with no shared code. See the text/code audit doc for details.
