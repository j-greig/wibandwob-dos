  A TypeScript module that drops a window into the WibWob-DOS desktop. It gets:   
  [36m- [0mA blessed window frame (chrome, drag, resize, close, z-order)                 
  [36m- [0mCommands registered in the menu, palette, and control API                     
  [36m- [0mAccess to the screen, theme, and window manager via a host object             
  [36m- [0mLifecycle hooks: cleanup, restyle, resize, input                              
                                                                                  
                                                                                  
  Render policy for microapps:                                                    
  [36m- [0mkeep one local render function per window or surface where possible           
  [36m- [0mmutate widgets inside that render function, not ad hoc across event handlers  
  [36m- [0muse [38;5;223m[48;5;236m win.onResize() [0m as the re-layout seam                                    
  [36m- [0muse [38;5;223m[48;5;236m win.describeState() [0m for semantic state, not UI scraping                 
  [36m- [0mprefer imports from [38;5;223m[48;5;236m src/services/microapp-sdk.ts [0m over direct [38;5;223m[48;5;236m src/core/* [0m
